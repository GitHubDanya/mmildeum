# Lunar Landing Site Navigator
We are a team of 5 third-year high school students from the Magshimim Cyber program with strong skills in programming, software, and analytical problem-solving.
We chose the CLPS Lunar Mission Browser challenge because it combines lunar exploration, data visualization, and technical engineering in a way that fits our interests well. 

### FOR CONTRIBUTORS
To handle high traffic flow, some conventions for working with the repository were put in place.

**[Follow the commit instructions!!!](https://github.com/GitHubDanya/mmildeum/blob/main/docs/COMMIT_CONVENTIONS.md)** This is essential to keep everything clear and concise.
Make sure to separate each change into it's own commit. Do not lob a lot of features into a single giant commit, make life easy for reviewers :)

This repo features AI reviews and workflows for verifying the project building correctly. The AI review workflow runs locally on the computer of the repo owner.
If it doesn't work, the computer is most likely offline.

Run AI reviews with `/review`. You could also include an optional message to specify the review scope with `/review [msg]`.
